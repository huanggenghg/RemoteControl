# 整合自查

本会话内逐项只读自查；没有独立代理评审，也没有提交、合并或推送。

- 共享服务仅增加可选的最后派发检查。现有普通调用/尾随 canContinue lambda 的绑定未变；两个主应用 Debug 变体构建通过。
- 控制器操作串行化；编辑检查 PREPARING/CLAIMED 和活动试运行，并持有编辑执行门。停止先于编辑或发生于登记时，保存不能重新打开自动执行门。
- 保存配置和匹配的新闹钟身份由同一 SharedPreferences commit 写入；ARMED 仅在系统 API 接受安排及持久化确认后显示。
- scheduleId 保持不变，任务 id 更新；旧事件身份不能领取新任务。下一次安排及接纳/领取均检查每日消费日期。
- closed_at 与 consumed_at 分开：未领取的跳过事件不消费整天；已领取后失败/取消不释放当天。
- 保存结果来自控制器返回值。停用编辑不启用；缺权和时区标记保留；未改变配置不换身份或重排。
- 设备回归复现并修复两项最终确认缺口：系统登记后权限丢失；同步登记过程中调用方取消。二者均进入停用和清理，不覆盖真实历史。
- 失败 commit/取消失败不能报告成功；清理使用 NonCancellable，并保留异常和未确认状态。
- ViewModel 保留同一次保存，旋转不会重复登记；原图标 15 个资源逐文件哈希保持一致。
- 当前目录原暂存差异、无关文件哈希及 EXACT 来源已与实施前清单核对。

最终自查：103项本地测试、115项设备用例通过；实际编辑和未经编辑的两个生产定时场景分别仅点击一次。数据、设置和来源逐项恢复/核对，无排队测试闹钟或私有备份。实际截图已查看。完整证据以 report.md / verification.json / final-device-state.json 为准。真机、厂商后台策略和实际重启不在本次验收范围。
