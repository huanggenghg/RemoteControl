# AutoClick 离线版试用说明

适用于支持 Android APK 安装和系统无障碍服务的 Android 7.0 及以上设备。本版无需账号、付费或网络；安装包中已附隐私与权限说明、使用指南。应用不会自动解锁手机或打开目标页面。

开发者：黄耿。反馈邮箱：huanggeng0607@163.com。安装失败时也可以通过此邮箱反馈机型、系统版本和错误提示。

## 安装与第一次试用

1. 使用开发者提供的正式签名 APK。可以对照同包 `SHA256SUMS` 中的 SHA-256 校验安装包；不要使用来源不明的改包。
2. 已装旧测试版的用户先确认签名是否相同。签名不同不能直接覆盖安装；建议先用另一台设备试用，保留原设备记录。不要为安装而直接卸载含有重要任务的旧版。
3. 打开应用，先阅读“隐私与权限说明”，再决定是否开启无障碍服务。说明和指南在未授权时即可查看。
4. 用不含付款、发送、删除等操作的自建测试页面，录制一到两个普通按钮。先停用定时任务，运行一次“5 秒后试运行”，并核对实际点击次数。
5. 试用停止按钮，确认可以中止后续点击。已经发送的点击不能撤销。
6. 再尝试一个临近的定时计划，保持亮屏、解锁和正确页面；记录是否准时开始、最近结果及有无重复。计划后五秒内未开始会跳过，系统调度不保证每台手机都准时。

从 APK 文件安装后，部分系统会额外限制无障碍授权。请先核实包来源，依据本机系统说明自行决定是否允许受限设置；不要关闭系统安全保护。不同厂商的入口可能不同，遇到问题可以先反馈。

## 数据与升级

任务、录制、历史和恢复草稿仅保存在当前设备。应用不提供云备份或设备迁移。删除任务与清空录制分别操作；系统“清除应用数据”及卸载会清除全部本地记录。

后续版本使用同一正式签名并增加版本号后，可以覆盖升级。首批试用仍需收集不同品牌真机的后台、重启和权限撤销表现；构建检查与历史模拟器通过记录不能代替这些验收。
